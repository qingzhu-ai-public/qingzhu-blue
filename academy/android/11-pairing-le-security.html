配对与 LE 安全：createBond 与加密事件

写配置返回 0x05/0x0F，是安全层问题。这一课讲 Android createBond、绑定状态广播、加密启用，以及恢复出厂两侧密钥清理。

平台：Android/Kotlin约 12 分钟含交互演练前置：B4

第 1 步createBond 与绑定状态

device.createBond()
// 监听 ACTION_BOND_STATE_CHANGED: BOND_NONE→BONDING→BONDED
// 读写遇 0x05/0x0F 时触发配对/加密
本步收束：createBond 异步，监听绑定状态广播。

第 2 步绑定重连要重新启用加密

绑定保存 LTK/IRK，但重连后不自动加密，要用保存的 LTK 重新启用。0x05 认证不足、0x0F 加密不足是安全层（配对加密可解）；0x08 授权不足是业务层（走厂商授权）。

本步收束：重连重新启用加密；分清安全层与业务层错误。

第 3 步恢复出厂两侧密钥一起清

重点 · 高频客诉外设恢复出厂丢密钥，手机留旧 LTK→加密失败「连上但读写报错/反复弹配对」。用 removeBond()（反射/系统设置）删旧绑定重新配对。把恢复出厂列入测试用例。
本步收束：密钥失效要删旧绑定重配，两侧一起清。

动手走绑定→加密，再恢复出厂看故障

点 createBond→BONDED→启用加密。再点「外设恢复出厂」后启用加密，看密钥不匹配；点 removeBond 清理后重新配对恢复。
