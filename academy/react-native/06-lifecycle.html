生命周期：移除订阅与断连销毁

RN 离开页面要 remove 订阅、cancelDeviceConnection、必要时 manager.destroy。这一课讲三级清理与前后台切换。

平台：React Native/TS约 20 分钟ble-plx 3.x含两场交互演练跨端对照
1清理remove
2断连cancel
3销毁destroy 边界

第 1 步移除订阅：三级清理清单

const sub = d.monitor(...);
// 退出: sub.remove();
await manager.cancelDeviceConnection(id)
// 完整清单：订阅 → 连接 → 扫描，逐级清
useEffect(() => {
  return () => {                    // 组件卸载
    monitorSub?.remove();           // 1 退订 CCCD
    discSub?.remove();              // 2 移除 onDisconnected 监听
    stateSub?.remove();             // 3 移除 onStateChange 监听
    manager.stopDeviceScan();       // 4 停扫
    manager.cancelDeviceConnection(id); // 5 断连
  };
}, []);
级对象动作漏掉的后果
1Subscription（monitor/onDisconnected/onStateChange）sub.remove() 3.x幽灵回调进已卸载组件
2连接cancelDeviceConnection / device.cancelConnection 3.x孤儿连接费电、占对端连接槽
3扫描stopDeviceScan() 3.x射频常驻费电
App 退出BleManagermanager.destroy() 3.x原生资源不释放
收束：remove+cancel。

第 2 步销毁与前后台

// App 退出 manager.destroy()
// 后台持续传输靠原生模块（F7）
  • destroy 的边界：销毁原生 manager 与全部连接；destroy 后该实例不可再用，要重新 new BleManager()。多页面共享单例时，只在 App 退出销毁。
  • 前后台：用 RN AppState 监听；退后台停扫/按需断连，回前台先过权限门×状态门（F2）再恢复。
  • 后台持续传输：iOS 挂起 JS、Android 受调度；要原生前台服务/后台模式 + 原生模块事件回传（F7）。
AppState.addEventListener('change', (state) => {
  if (state === 'background') {
    manager.stopDeviceScan();
  } else if (state === 'active') {
    // 过两道门 → 恢复扫描/重连（新会话，F4）
  }
});
重点不清理泄漏连接/费电。remove 管订阅、cancel 管连接、destroy 管实例——三个动词三个层级，别混用。
收束：页面级 remove+cancel+stop；App 级 destroy；后台靠原生。
