# 蓝牙温湿度计 · iOS MVP

用一台 iPhone 查找教学设备、连接并读取温湿度。第二台 iPhone 可以运行同一个 App，模拟供连接的外设。

- [交互原型](https://qingzhu-ai-public.github.io/qingzhu-blue/examples/ios/thermometer-mvp/prototype/index.html)
- [首次运行、源码讲解和双机验收](https://qingzhu-ai-public.github.io/qingzhu-blue/#ios/thermometer-mvp/overview)

在支持所需 iOS SDK 的 Mac 上用 Xcode 打开 `Thermometer.xcodeproj`。示例最低 iOS 16。选择 Thermometer target 并设置签名团队和可用的 Bundle Identifier，再选真机运行。原型里的数据用于演示界面，完整蓝牙收发以真机验收为准。
