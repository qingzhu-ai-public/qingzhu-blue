订阅与通知：setNotifyValue 一行顶两步

iOS 的 setNotifyValue(true) 由系统帮你完成本地登记+写 CCCD 两步，比 Android 省心。这一课把订阅 API、notify 与 indicate 的 ATT 差异、订阅确认与验证、重连重订逐一讲清，并演练 iOS 一步与 Android 两步的完整对照。

第 1 步setNotifyValue 系统代劳两步

peripheral.setNotifyValue(true, for: ch)
// didUpdateNotificationStateFor → isNotifying
// 值更新 → didUpdateValueFor
API / 回调 / 字段作用引入
setNotifyValue(_:for:)true 订阅 / false 退订；系统同时做本地登记 + 写远端 CCCDiOS 5
peripheral(_:didUpdateNotificationStateFor:error:)订阅/退订的结果确认iOS 5
ch.isNotifying当前订阅状态（确认回调后更新）iOS 5
ch.properties 的 .notify / .indicate特征支持哪种推送；两者都没有则订阅必失败iOS 5
.notifyEncryptionRequired / .indicateEncryptionRequired订阅要求加密链路（触发配对，C10）iOS 6
重点 · 与 Android 对照Android 要手动 setCharacteristicNotification + writeDescriptor(CCCD) 两步；iOS setNotifyValue 一行，系统代写 CCCD。但仍要等 didUpdateNotificationState 确认 isNotifying。CCCD 值：notify=0x0001，indicate=0x0002，系统按特征能力自动选。
本步收束：iOS 一行订阅，等状态回调确认；CCCD 系统代写。

第 2 步didUpdateValueFor 收数据：notify 与 indicate

订阅后设备发通知/指示都走 didUpdateValueFor。Indicate 的确认由系统协议栈自动回。解码放工作线程，别堵 delegate。

推送方式ATT 操作确认吞吐典型用途
NotifyHandle Value Notification (0x1B)无（可丢）高，可连发传感器流、UART 透传
IndicateHandle Value Indication (0x1D)逐条确认（系统自动回）低，一问一答关键测量值（如 2A6E 温度测量）
  • App 层无感：两种方式都走同一个 didUpdateValueFor，ch.value 更新；indicate 的 ATT 确认由协议栈自动完成，不占你的代码。
  • indicate 慢是协议本质：每条都要等对端确认才能发下一条，别指望它跑吞吐；要快选 notify 特征。
  • 回调线程：delegate 回调在初始化时指定的 queue（nil=主队列）；重解码/写文件丢到工作线程，别堵回调。
  • 与读共用回调：分不清是读回还是通知？看上下文（你刚发过 readValue 吗），或按 ch.uuid 分流。
本步收束：值走 didUpdateValueFor；Indicate 系统签收；notify 快、indicate 稳。

第 3 步订阅后触发新读数验证

别把 setNotifyValue 调用当成功，等 isNotifying 并触发新读数看是否收到、字节序对。重连重新 setNotifyValue。

  • 三段验证：① didUpdateNotificationStateFor 无 error 且 isNotifying=true；② 触发一次新测量（按设备按钮/发测量命令）；③ didUpdateValueFor 真收到、字节解码正确。
  • 订阅失败常见 error：insufficientAuthentication / insufficientEncryption → 特征要求加密链路，走配对（C10）；特征不支持 notify/indicate → 先查 properties。
  • 重连必重订：本地订阅登记随连接会话作废；即使设备端 CCCD 因配对保留，iOS 侧也要重新 setNotifyValue 才能收到回调。把「订阅清单」存在 App 里，didConnect 后逐条重放。
  • 退订：setNotifyValue(false, for:)，同样等状态回调；不再需要的订阅及时退，省设备端资源。
本步收束：等 isNotifying+新读数验证；重连重订；失败先查 properties 与加密要求。
