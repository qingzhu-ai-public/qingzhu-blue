配对与安全：系统弹窗，无 createBond

iOS 没有 createBond API，配对由系统在访问受保护特征时自动弹窗。这一课把系统配对的触发链、四个安全类 ATT 错误码、解绑与恢复出厂的密钥失配处理逐一讲清，并教你区分「链路安全」与「业务授权」两层。

第 1 步访问受保护特征触发系统弹窗

iOS 无 createBond。读写需要认证/加密的特征时，系统自动弹配对框，完成后密钥由系统保存。App 不直接管密钥。

能力AndroidiOS
主动发起配对createBond()无 API；访问受保护特征间接触发
解除绑定removeBond()（反射/隐藏）无 API；设置→蓝牙→忽略此设备
查绑定状态bondState + 广播无 API；只能靠操作结果推断
密钥保存系统栈系统栈（App 不可见）
  • 触发条件：特征声明需要认证/加密（如 properties 带 .notifyEncryptionRequired，或设备端 ATT 权限表要求），普通特征不会弹。
  • 想「提前配对」：没有正规 API；工程上读一次受保护特征（如设备信息里要求加密的项）来触发。
  • 配对方式：Just Works / 数字比较 / passkey 由双方 IO 能力决定（通用基础 A 板），iOS 弹窗样式随之变化。
本步收束：配对系统代管，App 不 createBond；受保护操作触发弹窗。

第 2 步安全类 ATT 错误码：四个码逐一认

读写回调 error 为 .insufficientAuthentication / .insufficientEncryption 时，系统会引导配对/加密；重试该操作。区分安全层与业务授权（厂商协议）。

CBATTError.CodeATT 值含义对策
.insufficientAuthentication0x05链路未认证（没配对）系统弹配对；完成后重试
.insufficientEncryption0x0F链路未加密同上，配对后链路加密
.insufficientEncryptionKeySize0x0C密钥长度不够（设备要求更高）重新配对协商更强密钥
.insufficientAuthorization0x08设备端应用层未授权走厂商业务授权流程，不是配对能解决的

枚举 CBATTError.Code 自 iOS 5（ObjC 常量），Swift 的 CBATTError 结构体自 iOS 10 命名。错误从 didUpdateValueFor / didWriteValueFor / didUpdateNotificationStateFor 的 error 参数来，转成 CBATTError 判断：

func peripheral(_ p: CBPeripheral, didUpdateValueFor ch: CBCharacteristic, error: Error?) {
  if let e = error as? CBATTError {
    switch e.code {
    case .insufficientAuthentication, .insufficientEncryption:
      // 系统已引导配对；用户完成后重试 readValue
      break
    case .insufficientAuthorization:
      // 业务授权：走厂商协议（token/握手），别死循环重试
      break
    default: break
    }
  }
}
重点 · 两层分清链路安全（配对/加密）由系统管，错误码是 ATT 标准码；业务授权（厂商 token、账号绑定）是应用层协议，错误可能表现为 insufficientAuthorization 或厂商自定义回执。配对成功≠业务授权通过，两层各自验证。
本步收束：安全错误系统引导；业务授权另走厂商；重试要有上限别死循环。

第 3 步解绑在系统设置，恢复出厂要清

重点解绑在「设置→蓝牙→忽略设备」，App 无 API。外设恢复出厂后手机旧密钥不匹配→反复弹配对/读写错；引导用户忽略设备重配。两侧一起清。
  • 失配的症状：连接成功但读写报安全错、配对框反复弹、或连接后立刻断（设备拒绝旧密钥）。
  • 处理三步：① 识别症状（安全错误连续出现）；② 提示用户「设置→蓝牙→忽略此设备」；③ 重新连接触发新配对。App 内给图文引导，别只甩错误码。
  • 固件侧配合：恢复出厂务必清绑定表；提供「清除配对」命令（业务层）让用户不用跑系统设置。
  • 没有 bondState 可查：iOS 不告诉你绑没绑，只能靠操作结果推断——把「安全错误计数」作为失配信号。
本步收束：解绑靠系统设置；恢复出厂两侧清；失配靠症状识别。
