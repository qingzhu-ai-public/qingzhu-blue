读写与订阅：read/write/subscribe

readCharacteristic、writeCharacteristicWithResponse/WithoutResponse、subscribeToCharacteristic。这一课讲三种操作与字节解析。

第 1 步读写

await ble.readCharacteristic(ch)
await ble.writeCharacteristicWithResponse(ch, value: bytes)
// ch 是三元定位（E1）；值是 List<int> 原始字节
final ch = QualifiedCharacteristic(
  characteristicId: Uuid.parse('476cdf45-6063-43a1-b8e2-8c1fbed00602'),
  serviceId:        Uuid.parse('476cdf45-6063-43a1-b8e2-8c1fbed00601'),
  deviceId: deviceId);

final bytes = await ble.readCharacteristic(ch);   // Future<List<int>>
await ble.writeCharacteristicWithResponse(ch, value: [0x01]);
// 教学协议：写 0x01 → 外设回一帧 40 02 <temp> 03 BF 13
await ble.writeCharacteristicWithoutResponse(ch, value: payload);
// 无应答：快，但丢了不知道
操作返回可靠性适用
readCharacteristic 5.xFuture<List<int>>一次快照初值/低频量
writeCharacteristicWithResponse 5.xFuture<void>（等 ATT 应答）失败会抛错关键命令（如 0x01 请求帧）
writeCharacteristicWithoutResponse 5.xFuture<void>（不等应答）丢包无感知高频流数据、可容忍丢失
收束：有/无响应两种写。

第 2 步订阅与字节解析

ble.subscribeToCharacteristic(ch).listen((bytes){ /* 解析 */ })

订阅的本质是写 CCCD（0x2902 描述符）开启 notify/indicate，reactive_ble 在库内替你完成；cancel 订阅流时库写回 CCCD 退订。notify 无应答、indicate 有应答，库按特征属性自动选择。

final sub = ble.subscribeToCharacteristic(ch).listen((bytes) {
  if (bytes.length < 7 || bytes[0] != 0x40) return; // 防截断/异帧
  final bd = ByteData.sublistView(Uint8List.fromList(bytes));
  final t = bd.getInt16(2, Endian.little) / 100.0;  // sint16：零下靠补码
  final h = bd.getUint16(5, Endian.little) / 100.0;
  setState(() { temp = t; hum = h; });
});
// dispose: sub.cancel() → 库写回 CCCD 退订
重点订阅流 listen 收值；解析小端+符号同通用。大端读 C4 09 会得 50185（501.85°C）——字节序错是 BLE 解析第一大坑。
收束：三种操作 + 小端解析；订阅的开关由库代写 CCCD。

项记住

      
读readCharacteristic(ch) → Future<List<int>>

      
关键写writeCharacteristicWithResponse（等应答，失败抛错）

      
流式写WithoutResponse（快，丢包无感知）

      
订阅subscribeToCharacteristic → Stream<List<int>>；库代写 CCCD

      
退订cancel 订阅流（库写回 CCCD）

      
解析ByteData + Endian.little；温度 getInt16、湿度 getUint16；×0.01

      
防坑先验长度/帧头；大端误读、零下补码是两大坑
