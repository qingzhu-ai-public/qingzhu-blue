读写与解析：read/writeCharacteristicValue

readCharacteristicValue / writeCharacteristicValue 操作特征值（ArrayBuffer），写类型 WRITE=1 / WRITE_NO_RESPONSE=2。字节解析同通用：小端+符号。这一课把读写代码、分片规则与解码工坊做齐。

平台：HarmonyOS/ArkTS约 24 分钟API 10含两场交互演练跨端对照
1读写ArrayBuffer
2解析小端符号
3闭环指令→响应
4动手解码工坊

第 1 步读写 API

dev.readCharacteristicValue(characteristic)
dev.writeCharacteristicValue(characteristic, value, writeType)
API版本说明
readCharacteristicValue(ch)API 10读特征，值在返回对象的 characteristicValue（ArrayBuffer）
writeCharacteristicValue(ch, writeType)API 10要写的数据先放进 ch.characteristicValue，再传对象+写类型
readDescriptorValue / writeDescriptorValueAPI 10描述符读写（CCCD 由系统代写，一般不用手动碰）
GattWriteType.WRITE = 1API 10有响应：对端确认，可靠
GattWriteType.WRITE_NO_RESPONSE = 2API 10无响应：快，但丢了不知道
// 读：Promise 返回带值的特征对象
dev.readCharacteristicValue(target).then((ch: ble.BLECharacteristic) => {
  let bytes = new Uint8Array(ch.characteristicValue);
  // bytes 就是原始数据，进入第 2 步解析
});

// 写：先把 ArrayBuffer 塞进特征对象
let cmd = new Uint8Array([0x01]).buffer;
target.characteristicValue = cmd;
dev.writeCharacteristicValue(target, ble.GattWriteType.WRITE)
  .then(() => { /* 对端已确认 */ });
  • 串行：读写都要等上一步回调（2900011），Promise 链排队。
  • 分片：单包有效载荷 = MTU − 3；长数据先协商 MTU（D4）再切片循环写。
  • 写类型选：控制指令用 WRITE（要确认）；高频流数据且特征支持时用 WRITE_NO_RESPONSE。
收束：读写按特征对象，值走 ArrayBuffer；writeType 分有/无响应。

第 2 步解析：小端 + 符号

6A 09 → 0x096A=2410 ×0.01 = 24.10°C
DA FD → sint16 -550 → -5.50°C
// ArkTS 用 DataView 一步到位（第二参数 true = 小端）
let dv = new DataView(ch.characteristicValue);
let tempRaw = dv.getInt16(offset, true);   // sint16 小端
let temp = tempRaw * 0.01;
let humiRaw = dv.getUint16(offset2, true); // 湿度 uint16 无符号
重点小端+温度带符号，两大坑同 A4/B14。BTHome 对象表：0x02 温度 sint16×0.01、0x03 湿度 uint16×0.01、0x01 电量 uint8、0x0C 电压 uint16×0.001。
收束：getInt16(offset, true) 就是「小端+符号」的标准答案。

第 3 步教学闭环：指令 → 响应

D9 实战的教学设备：服务 476CDF45-…-0601，特征 …-0602（READ+WRITE）。写指令 0x01，设备回 BTHome 帧：

写:  01                          // 请求一帧温湿度
读:  40 02 C4 09 03 BF 13        // BTHome v2 帧
     │  │  └──┬─┘ │  └──┬─┘
     │  │   温度对象  │  湿度对象
     │  └ 0x02      └ 0x03
     └ 0x40 = v2 不加密定时
解析: C409 → 0x09C4 = 2500 → 25.00°C
      BF13 → 0x13BF = 5055 → 50.55%
  • 对象 ID 必须升序；遇到未知 ID 立即停（BTHome 规范）。
  • 湿度 50.55% 合法（0–100）；解析出 104.02% 说明字节错位或设备故障，要报越界而不是显示。
  • 这套 UUID/指令/帧格式与 Android B14、iOS C11 完全一致——三端 App 可连同一台设备。
收束：写 0x01 → 读帧 → 按对象表解析；三平台同一口径。
