第 1 步六步流程

scanForDevices → connectToDevice → discoverServices
→ subscribeToCharacteristic → 解析 → UI
步API课验收点
1 扫描scanForDevices(withServices:[476c…0601]) 5.xE3过滤命中、id 去重
2 连接connectToDevice(id) 5.xE4connected 才下一步；cancel 旧流再重连
3 发现discoverServices(deviceId) 5.xE4拿到 …0602 特征（READ+WRITE）
4 订阅/请求subscribeToCharacteristic + write 0x01 5.xE5关键命令带应答写；收帧
5 解析ByteData 小端 getInt16/getUint16 ×0.01E525.00/26.50 交替、湿度 50.55
6 UI/清理setState + dispose 三 cancelE6退页无幽灵回调、无孤儿连接
收束：全 Stream 链。

第 2 步双端验收与样例工程

同一 Dart 代码跑 Android+iOS，对照权限/后台差异；第二设备当外设发值验收。

对照项AndroidiOS
权限12+ SCAN/CONNECT 弹窗；旧系统位置plist 两键，首次自动弹窗
设备 idMAC（可能随机化）系统 UUID，不能硬编码
MTUrequestMtu 可协商不能协商，只能查询
专属操作requestConnectionPriority / clearGattCache调用抛 UnSupportedOperationException
后台原生前台服务挂起；后台模式是原生能力
  • 双机验收：第二台设备跑教学外设（服务 476cdf45-…0601，特征 …0602 READ+WRITE）；手机写 0x01，外设回帧 40 02 <temp> 03 BF 13，温度 25.00/26.50 交替、湿度固定 50.55%。
  • 对日志不看 UI：每步打印 API 结果与原始字节；UI 数字必须能从日志字节复算。
  • 样例工程：examples/flutter/thermometer-mvp（pubspec 锁 reactive_ble 5.6.0 / permission_handler 12.0.3 / device_info_plus 11.5.0），lib 下 main.dart / frame.dart / permissions.dart 与本课一一对应；附浏览器原型可先演练流程。
收束：双端+双机验收。
