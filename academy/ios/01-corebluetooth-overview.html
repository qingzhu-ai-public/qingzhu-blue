CoreBluetooth 全景：中心与外设的 API 地图

iOS 用 CoreBluetooth 框架做 BLE。CBCentralManager 当中心扫描连接，CBPeripheralManager 当外设。这一课摆清对象模型与 delegate 回调驱动。

平台：iOS/Swift约 12 分钟含交互演练前置：通用基础
1对象四个类
2角色central/peripheral
3delegate回调
4动手认 API

第 1 步Manager → Peripheral → Service → Characteristic

CBCentralManager      扫描/连接（中心）
   ↓ didDiscover → CBPeripheral
CBPeripheral          discoverServices / readValue / setNotifyValue
   ↓ CBService → CBCharacteristic → CBDescriptor
CBPeripheralManager   当外设发广播/提供属性表
本步收束：中心用 CBCentralManager+CBPeripheral；外设想用 CBPeripheralManager。

第 2 步一切靠 delegate 回调

所有操作异步，结果走 CBCentralManagerDelegate / CBPeripheralDelegate：didDiscover、didConnect、didDiscoverServices、didUpdateValueFor… 不能同步等结果。

重点 · 与 Android 对照Android 的 BluetoothGattCallback ≈ iOS 的两个 delegate；Android 句柄 ≈ iOS 直接拿 CBCharacteristic 对象（不用记句柄）。
本步收束：delegate 回调驱动；iOS 直接持对象不记句柄。

第 3 步iPhone 既能当中心也能当外设

iPhone 默认中心+Client；用 CBPeripheralManager 也能当外设+Server（C 选修）。两套角色可交叉，与 Android 一致。

本步收束：角色可交叉，iPhone 双角色都行。
