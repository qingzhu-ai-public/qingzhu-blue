# 06　明明装了库，怎么还是连不上

从开发构建开始往下查。原生模块加载失败先检查安装包是否重新编译；扫描为空先查权限、蓝牙开关和服务过滤；连接后不能读，打印服务发现的 UUID 和属性；读到了数组再查字节顺序。

两个系统可以通过同一套界面对接同一外设。状态报错、设备标识、后台策略各有平台差异。记录出错的系统版本和操作阶段，遇到库接口没暴露的能力，翻回原生指南定位。

**练习**　用同一份配置分别跑 Android 和 iOS，保留各自的回包十六进制。把失败写成可复现步骤。

**一句话**　从安装包到最后一个字节，哪一步没有结果就在哪一步查。

**面试题**　热更新可以修复系统用途说明写错吗？

用途说明在编进安装包的原生配置里，需重新构建和安装。
