权限与状态：permission_handler 跨平台

Flutter 权限要分平台处理：Android 12+ SCAN/CONNECT、旧系统位置；iOS plist。用 permission_handler 统一申请，再用 BleStatus 六态门控扫描。

平台：Flutter/Dart约 20 分钟permission_handler 12.x含两场交互演练跨端对照

第 1 步跨平台权限

// permission_handler
await [Permission.bluetoothScan, Permission.bluetoothConnect].request()
// iOS 另需 plist 用途声明
// 样例工程 permissions.dart 的真实分支（device_info_plus 判 SDK）
final sdk = (await DeviceInfoPlugin().androidInfo).version.sdkInt;
final permissions = sdk >= 31
    ? [Permission.bluetoothScan, Permission.bluetoothConnect]
    : [Permission.locationWhenInUse];
final statuses = await permissions.request();
return permissions.every((p) => statuses[p]?.isGranted ?? false);

// AndroidManifest.xml（库 README 官方写法）
<uses-permission android:name="android.permission.BLUETOOTH_SCAN"
    android:usesPermissionFlags="neverForLocation" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"
    android:maxSdkVersion="30" />

// iOS Info.plist：13+ 用 NSBluetoothAlwaysUsageDescription
// 12 及以下用 NSBluetoothPeripheralUsageDescription；首次使用自动弹窗
平台 / 版本声明运行时备注
Android 12+（SDK 31+）BLUETOOTH_SCAN / BLUETOOTH_CONNECTpermission_handler 弹窗neverForLocation 声明不推导位置，可免位置权限
Android 11 及以下ACCESS_FINE_LOCATION（maxSdkVersion=30）locationWhenInUse 弹窗旧系统 BLE 扫描按位置权限管
iOS 13+Info.plist NSBluetoothAlwaysUsageDescription首次使用自动弹窗，无需代码申请用途文案缺失会直接崩溃
iOS 12 及以下NSBluetoothPeripheralUsageDescription同上旧键，双键都写最稳
  • 拒绝处理：isGranted 为 false 时给「去设置」引导（permission_handler 的 openAppSettings()），别死循环弹窗。
  • iOS 撤销授权：用户在设置里关掉蓝牙权限，App 会被系统终止（对照 C2），重启后重新走门控。
收束：分平台申请，iOS 要 plist。

第 2 步适配器状态：BleStatus 六态门控

ble.statusStream.listen((s){ /* BleStatus.ready / poweredOff / unauthorized */ })
BleStatus含义能扫描吗处理
unknown状态尚未确定等初始化中，别操作
unsupported设备不支持 BLE否提示设备不支持
unauthorizedApp 未获蓝牙授权否回权限引导（第 1 步）
poweredOff蓝牙关闭否引导开蓝牙，监听恢复
locationServicesDisabledAndroid 定位服务关闭否Android only 引导开定位服务
readyBLE 完全可用能唯一放行态
ble.statusStream.listen((s) {
  if (s == BleStatus.ready) {
    // 恢复扫描/重连
  } else {
    // 停扫描、cancel 连接流、清队列，按态给引导
  }
});
// status 是当前值快照；statusStream 才是流（原稿笔误已修正）
重点ready 才扫描；分平台权限差异同 B2/C2。六态里只有 ready 放行；locationServicesDisabled 是 Android 专属态。
收束：权限门 × 状态门；statusStream 驱动清理与恢复。
