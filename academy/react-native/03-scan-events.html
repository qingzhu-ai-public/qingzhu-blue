扫描与事件：startDeviceScan

startDeviceScan(uuids,options,cb) 回调收 device；stopDeviceScan 停。这一课讲扫描参数、错误语义与去重。

平台：React Native/TS约 20 分钟ble-plx 3.x含两场交互演练跨端对照
1扫描startDeviceScan
2去重id
3错误err 即停扫

第 1 步扫描与参数

manager.startDeviceScan(['1809'], null, (err, device)=>{
  // device.id / name / rssi
})
manager.stopDeviceScan()
参数类型说明
UUIDsArray<UUID> | null按广播服务 UUID 过滤；null = 全收（与 Flutter 空列表语义同）
optionsScanOptions | nullallowDuplicates（iOS 才生效，默认 false）；Android 侧重复默认上报
listener(error, device) => voiderror 非 null = 扫描已失败停止，必须重新 startDeviceScan
Device 字段用途注意
id连接与去重的键Android MAC（可能随机化）/ iOS UUID
name / localName展示可空可重复，别当键
rssi排序/近场波动大，只配排序
serviceUUIDs / serviceData广播服务数据BTHome 服务数据从这里取
manufacturerData / rawScanRecord厂商数据/原始广播base64 字符串，先解码（F5 同功）
收束：回调收 device，及时 stop。

第 2 步去重与错误处理

按 device.id 合并；过滤字段须真实在广播里；RSSI 只配排序。

const devices = new Map<string, Device>();
manager.startDeviceScan([SVC], null, (err, device) => {
  if (err) {
    // 扫描已停止：记日志、按错误码处理、必要时重启
    console.warn(err.errorCode, err.message);
    return;
  }
  devices.set(device.id, device); // 同 id 覆盖，rssi 取最新
  setList([...devices.values()]);
});
// 连上目标或离开页面：manager.stopDeviceScan()
重点及时 stopDeviceScan 防费电。扫描没有超时自动停；err 回调后不重启就永远没数据——这是 plx 与 Stream 系库最大的语义差异。
收束：id 去重 + stop 停扫 + err 重启，三件事缺一不可。
