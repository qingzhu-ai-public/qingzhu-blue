厂商兼容与机型矩阵：平台行为要实测

同一份代码在不同厂商手机上行为不同：扫描限流阈值、后台策略、GATT 回调线程、连接槽数。这一课把常见差异点、能力查询 API、可复测矩阵、单变量隔离与记录规范逐一讲清，并给出官方依据。

第 1 步常见厂商差异点

差异点表现应对
扫描限流 / 熄屏5次/30s 阈值、熄屏降级各家不同带过滤 + 周期重启（B3）
GATT 回调线程Binder 线程行为、并发差异统一 post 进 worker（B9）
连接槽数未 close 的 GATT 客户端上限约 6–7及时 close，防 133（B4）
autoConnect 重连重连时机、缓存刷新差异直连 + 自己管重试
后台 FGS / CDM事件投递、保活策略厂商限制实测豁免（B10）
PHY / offload2M/Coded、硬件过滤支持不一先查能力 API
本步收束：差异是平台行为不是你的 bug，要实测记录、防御性编程。

第 2 步能力查询 API：先问再做

方法（BluetoothAdapter）查什么级别
isOffloadedFilteringSupported()硬件扫描过滤21
isOffloadedScanBatchingSupported()硬件扫描批处理21
isLe2MPhySupported() / isLeCodedPhySupported()2M / Coded PHY26
isLeExtendedAdvertisingSupported()扩展广播26
isMultipleAdvertisementSupported()能否当 Peripheral21
本步收束：用能力 API 先问硬件支不支持，再决定走哪条路。

第 3 步建可复测矩阵，单变量隔离

结果指向

换外设才复现外设侧：固件 / 硬件批次
怎么换都复现共有约定：广播 / 服务表 / 协议

第 4 步记录四要素：版本 + 固件 + 步骤 + 结果

矩阵每格记录：机型 / Android 版本 / 外设固件 / 操作顺序 / 结果。没有这份记录，「偶现」永远只是传说；有了它变成可查事实。把恢复出厂、熄屏、后台、多设备竞争都列入固定用例。
