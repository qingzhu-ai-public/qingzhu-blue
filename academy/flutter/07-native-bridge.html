原生桥接：MethodChannel 调已有蓝牙任务

已有原生蓝牙 SDK/任务时，用 MethodChannel/EventChannel 桥接给 Dart，复用原生能力（后台/厂商兼容）。reactive_ble 自己就是这么实现的。

平台：Flutter/Dart + Kotlin/Swift约 22 分钟platform channels含两场交互演练跨端对照

第 1 步MethodChannel：方法调用

// Dart
const MethodChannel('ble/task').invokeMethod('start', args)
// Kotlin/Swift 侧实现 handler 调原生 SDK
// Dart 侧
const channel = MethodChannel('ble/task');
try {
  final r = await channel.invokeMethod('start', {'mac': mac});
} on PlatformException catch (e) {
  // 原生 result.error(code, msg, details) 到这里
}

// Kotlin 侧（MainActivity.configureFlutterEngine）
MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "ble/task")
  .setMethodCallHandler { call, result ->
    when (call.method) {
      "start" -> {
        val mac = call.argument<String>("mac")
        nativeBleTask.start(mac)     // 已有原生 SDK/任务
        result.success("ok")
      }
      else -> result.notImplemented()
    }
  }
通道形态用途
MethodChannel Flutter一次调用一次结果（Future）start/stop/config 等命令
EventChannel Flutter原生持续推 → Dart Stream扫描结果/通知帧/状态事件
BasicMessageChannel Flutter双向消息少用；自定义编解码场景
收束：方法调用走 MethodChannel。

第 2 步EventChannel：回调转 Stream

// 原生回调 → EventChannel sink → Dart Stream
// Kotlin：StreamHandler 把 SDK 回调接到 sink
EventChannel(messenger, "ble/events").setStreamHandler(
  object : EventChannel.StreamHandler {
    override fun onListen(args: Any?, sink: EventChannel.EventSink) {
      nativeBleTask.onFrame = { bytes ->
        mainHandler.post { sink.success(bytes.toList()) }
        // SDK 回调常在 binder 线程，回主线程再发
      }
    }
    override fun onCancel(args: Any?) {
      nativeBleTask.onFrame = null   // Dart cancel 时解绑
    }
  })

// Dart：receiveBroadcastStream 就是 Stream
final sub = const EventChannel('ble/events')
  .receiveBroadcastStream().listen((frame) { /* 解析 */ });
  • 何时自写桥：厂商私有 SDK、后台前台服务任务、库未覆盖的私有协议；常规 BLE 直接用 reactive_ble，别重复造桥。
  • 线程：通道调用在主线程；SDK 回调常在别的线程，post 回主线程再 sink.success。
  • 错误：result.error → Dart PlatformException；未注册/名字不一致 → MissingPluginException。
重点把原生回调转成 Dart Stream，复用原生后台/兼容能力。onCancel 必须解绑回调，否则 Dart 侧 cancel 后原生还在推。
收束：命令 MethodChannel、事件 EventChannel；线程与解绑别漏。
