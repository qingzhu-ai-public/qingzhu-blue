# 20　发版前，怎样在真机上测一遍

自己的手机跑通一次后，再检查用户拒绝授权、外设断电、两个设备同时连接时会发生什么。

## 把检查写成可重做的实验

| 实验 | 记录和验收 |
| --- | --- |
| 首次安装、允许和拒绝授权 | 显示的提示、是否能从设置恢复 |
| 角色互换、不同系统版本 | 两端型号、iOS、配件固件和角色 |
| 已连接时关掉外设 | 页面能否及时禁用操作，重连是否恢复 |
| 连续点击、取消、快速切页面 | 是否出现重复命令或旧回调更新页面 |
| 切后台、锁屏、系统终止 | 有无事件、进程是否恢复，分别记录 |
| 长时间或多设备 | 记录失败阶段、恢复耗时、吞吐和能耗 |

比较扫描耗时前先固定距离、测试时长和环境，记录样本数和是否首次连接。量吞吐时分别记发送字节、业务成功字节和时间。功耗测试设定相同屏幕和操作条件，用工具看趋势。单台单次的结果可用于复查问题，不能代表其他机型。

**动手验证**　从教学项目选扫不到、写失败、断开三种情况做验收，分别写下预期和实际。

**一句话记住**　先让测试能被重做，再比较数字。

## 自查题

1. **为什么要记录固件版本？** 同一型号的硬件可能因为固件不同表现不同。
2. **吞吐看 writeValue 的调用次数够吗？** 还要区分真正成功交付的字节和持续时间。
