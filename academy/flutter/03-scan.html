扫描：scanForDevices 流

scanForDevices(withServices:) 返回 Stream，listen 收 DiscoveredDevice。这一课讲扫描参数、过滤命中规则与去重停扫。

平台：Flutter/Dart约 20 分钟flutter_reactive_ble 5.6.0含两场交互演练跨端对照

第 1 步扫描流与参数

ble.scanForDevices(withServices:[Uuid.parse('1809')], scanMode:ScanMode.lowLatency)
  .listen((d){ /* d.id, d.name, d.rssi */ })
参数类型 / 默认说明
withServicesList<Uuid>（必填）按广播里的服务 UUID 过滤；官方建议总是指定，空列表 = 全收
scanModeScanMode.balancedlowPower / balanced / lowLatency 三档，延迟与功耗权衡
requireLocationServicesEnabledtrueAndroid 要求系统定位服务开启，否则扫描失败
DiscoveredDevice 字段用途注意
id连接与去重的键Android MAC（可能随机化）/ iOS UUID
name展示可能为空或重复，别当键
rssi排序/近场判断波动大，只配排序不配过滤
serviceUuids / serviceData / manufacturerData广播数据解析BTHome 等协议从这里取（E5/E8）
// Uuid.parse 支持 16 位短码，expanded 可扩成 128 位
final svc = Uuid.parse('1809');        // Health Thermometer 短码
final full = svc.expanded;             // 00001809-0000-1000-8000-00805f9b34fb
// 本教学协议用自定义 128 位：476cdf45-6063-43a1-b8e2-8c1fbed00601
收束：Stream listen 收设备。

第 2 步去重与停扫

按 d.id 合并列表；页面退出取消 subscription 停扫。过滤字段须真实在广播里。

final devices = <String, DiscoveredDevice>{};
final sub = ble.scanForDevices(withServices: [svc]).listen((d) {
  devices[d.id] = d;          // 同 id 覆盖：RSSI/广播数据取最新
  setState(() {});            // 或交给 StreamBuilder / 状态管理
});
// 停扫 = cancel 订阅（没有单独的 stopScan API）
@override void dispose() { sub.cancel(); super.dispose(); }
ScanMode延迟功耗适用
lowPower高低后台偶尔发现
balanced（默认）中中常规列表页
lowLatency低高用户盯着等设备的短窗口
重点及时 cancel 订阅防泄漏/费电。扫描没有「超时自动停」，连上目标后也应立刻 cancel 扫描流。
收束：id 去重 + cancel 停扫；过滤字段必须在广播里真实存在。
