权限与适配器：ACCESS_BLUETOOTH 与状态

鸿蒙要 ohos.permission.ACCESS_BLUETOOTH（API 10，user_grant 弹窗授权），声明+运行时申请缺一不可；用 access.getState 与 stateChange 门控蓝牙开关。这一课把权限申请代码、七态状态机与三平台差异讲清。

第 1 步权限声明与申请

// module.json5: ohos.permission.ACCESS_BLUETOOTH
// 运行时 abilityAccessCtrl.requestPermissionsFromUser
// module.json5 · requestPermissions（reason 必须给字符串资源）
"requestPermissions": [
  {
    "name": "ohos.permission.ACCESS_BLUETOOTH",
    "reason": "$string:bluetooth_reason",
    "usedScene": { "abilities": ["EntryAbility"], "when": "inuse" }
  }
]

// 运行时弹窗申请（user_grant）
import { abilityAccessCtrl, common } from '@kit.AbilityKit';
let atManager = abilityAccessCtrl.createAtManager();
atManager.requestPermissionsFromUser(context, ['ohos.permission.ACCESS_BLUETOOTH'])
  .then((data) => {
    if (data.authResults[0] === 0) { // 0 = 已授权
      // 再查蓝牙开关，STATE_ON 才扫描
    } else {
      // 引导用户去设置开启；拒绝后别死循环弹窗
    }
  });
权限授权方式起始版本用途
ohos.permission.ACCESS_BLUETOOTHuser_grant（弹窗）API 10扫描/连接/配对/广播，BLE 全场景一个权限
ohos.permission.USE_BLUETOOTHsystem_grant（安装即授）API 8旧 API 时代：查看蓝牙配置
ohos.permission.DISCOVER_BLUETOOTHsystem_grantAPI 8旧 API 时代：配置/扫描/配对
  • API 13 起权限组：蓝牙并入「设备发现和连接」权限组（与星闪、多设备协同统一授权弹窗）。
  • 不需要位置权限：鸿蒙 NEXT 的 BLE 扫描不像 Android 11 那样要 ACCESS_FINE_LOCATION（对照下表）。
  • 拒绝处理：authResults 非 0 时给「去设置」引导（startAbility 跳应用设置页），别反复弹。
平台声明运行时
鸿蒙module.json5 requestPermissionsrequestPermissionsFromUser 弹窗（一个权限管全部）
Android 12+BLUETOOTH_SCAN / CONNECT / ADVERTISE运行时授权；扫描可能还要位置权限（neverForLocation 可免）
iOSInfo.plist 两键首次使用自动弹窗；撤销授权 App 被终止（C2）
收束：声明+运行时申请，缺一不可；一个 ACCESS_BLUETOOTH 管 BLE 全场景。

第 2 步适配器状态：七态门控

import { access } from '@kit.ConnectivityKit';
access.getState()   // STATE_ON / STATE_OFF
access.on('stateChange')
BluetoothState值含义能扫描吗
STATE_OFF0蓝牙关闭否（2900003）
STATE_TURNING_ON1正在开启等
STATE_ON2蓝牙已开（经典+BLE）能
STATE_TURNING_OFF3正在关闭否，准备清理
STATE_BLE_TURNING_ON4LE-only 模式开启中等
STATE_BLE_ON5LE-only 模式（仅 BLE）能（BLE 操作）
STATE_BLE_TURNING_OFF6LE-only 模式关闭中否
access.on('stateChange', (state: access.BluetoothState) => {
  if (state === access.BluetoothState.STATE_ON ||
      state === access.BluetoothState.STATE_BLE_ON) {
    // 可以恢复扫描/重连
  } else if (state === access.BluetoothState.STATE_OFF) {
    // 停扫描、断连接、清队列，UI 提示开蓝牙
  }
});
// access.enableBluetooth() 可代码开蓝牙（需权限）；disableBluetooth 同理
重点STATE_ON 才扫描；监听 stateChange 处理用户关蓝牙。关蓝牙时所有连接会断，先清理再等恢复，别在 OFF 态重试操作（2900003）。
收束：七态里只有 ON/BLE_ON 可操作；stateChange 驱动清理与恢复。
